02 / Selected Work

Two systems, built end to end.

01

Machine Learning · MLOps · API Engineering

Diabetes Prediction MLOps PlatformA production-style ML service, small in scope but structured like the real thing.

A diabetes-risk classifier trained on the Pima Indians Diabetes dataset and served through FastAPI. Training and serving are cleanly separated: a training script evaluates the model on a held-out split and writes a versioned artifact with metadata, and the API loads it as an opaque artifact.

  • Liveness and readiness endpoints, with /ready returning 503 until the model is loaded
  • Validated request schemas, environment-driven config and structured logging
  • Tests, a Jenkins pipeline and a GitHub Actions quality gate
  • Multi-stage, non-root Docker image with a readiness health check

02

Cloud Infrastructure · Kubernetes · Predictive Scaling

CostWise Predictive Kubernetes AutoscalerScaling a workload before the traffic arrives, within a cost budget.

Explores predictive, cost-aware autoscaling as an alternative to purely reactive scaling. An LSTM forecasts near-term traffic from Prometheus metrics, a planner converts the forecast into required pods, and a cost optimiser picks the cheapest pod count that covers it within a simulated budget.

  • Forecast → capacity plan → cost optimisation → safety policy with cooldowns and step limits
  • Scales a demo marketplace Deployment on Minikube, with least-privilege access to the scale subresource
  • Traffic-generator scenarios plus experiments comparing fixed, HPA, predictive and cost-aware strategies
